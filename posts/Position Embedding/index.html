Positional Encoding (PE)

Problem with Simple Index-Based Encoding

All permutations of a sequence can look similar to the model if we only rely on token indices.

One approach would be to use the index of tokens directly. However, in the case of large sequences, the rightmost tokens will dominate.

Attempted Solution: Normalization

One possible solution is to normalize using the length of the sequence.

However, due to different sequence lengths, we will get different positional encodings for the same index across different sequences.

Sinusoidal Positional Encoding

The authors of the Transformer paper introduced sinusoidal functions to address this issue.

The positional encoding is defined as:

  • For even indices:

PE(pos, 2i) = \sin\left(\frac{pos}{10000^{\frac{2i}{d_{model}}}}\right)

  • For odd indices:

PE(pos, 2i + 1) = \cos\left(\frac{pos}{10000^{\frac{2i}{d_{model}}}}\right)

Understanding Sinusoidal Positional Encoding

Frequency Across Dimensions

  • Let ( i )
  • Each value of ( i ) corresponds to a different frequency of the sinusoidal function

This means: - Different embedding dimensions encode different frequency patterns - Together, they uniquely represent positions

Visualization Intuition

  • Lower dimensions → high frequency waves
  • Higher dimensions → low frequency waves

This creates a mix of: - Short-range patterns (rapid oscillations) - Long-range patterns (slow oscillations)

Positional Encoding Behavior

  • For even dimensions:

PE(pos, 2i) = \sin\left(\frac{pos}{10000^{\frac{2i}{d_{model}}}}\right)

  • For odd dimensions:

PE(pos, 2i + 1) = \cos\left(\frac{pos}{10000^{\frac{2i}{d_{model}}}}\right)

Key Observations

  • Earlier indices (smaller ( i )):
    • Capture short-range information
    • High-frequency variations
  • Later indices (larger ( i )):
    • Capture long-range information
    • Low-frequency variations

Connection to Binary Encoding

  • As frequency decreases, bit significance increases
  • Similar to binary representation:
    • Rightmost bits → change frequently (low significance)
    • Leftmost bits → change slowly (high significance)
  • Moving from right → left:
    • Repetition decreases
    • Importance increases

Locality Insight

For small values of ( i ):

  • ( PE(pos) ) and ( PE(pos + 1) ) are very different
  • ( PE(pos) ) and ( PE(pos + k) ) are more similar for larger k

Implication:

  • Helps distinguish nearby tokens
  • But less effective at distinguishing tokens that are far apart solely based on high-frequency components

Intuition Summary

Sinusoidal positional encoding works because:

  • It provides multi-scale representation of position
  • Enables the model to:
    • Learn relative positions
    • Generalize to longer sequences
  • Encodes position in a way that is:
    • Continuous
    • Deterministic
    • Non-learned
